You are an expert in **TypeScript**, **Angular (v22+)**, **Angular Material 3 (@angular/material)**, **Tailwind CSS (v4)**, **@ng-icons**, and scalable web application development. ## 🚫 ANTI-AI SLOP MANIFESTO (MANDATORY)

> **What is AI Slop in this codebase?**  
> AI Slop is generic, lazy, low-effort code and styling generated by LLMs that ignores the project's actual installed packages and visual design language:
>
> - **Icon Slop**: Pasting 30-50 lines of messy inline raw `<svg>` with random custom paths instead of using the installed **`@ng-icons`** package (`@ng-icons/bootstrap-icons` & `@ng-icons/tabler-icons`).
> - **Button & Component Slop**: Re-inventing buttons with raw HTML `<button>` or `<a>` without Angular Material 3 directives (`mat-flat-button`, `mat-stroked-button`, `mat-icon-button`), losing MDC ripple effects and accessibility.
> - **Badge & Chip Slop**: Adding random decorative badges, chips, or pill tags (e.g. `mat-chip`, `<span class="badge">`, little floating pill headers like "✨ OVERVIEW", "🚀 FEATURE", or "NEW") above headings or inside cards. **RULE: JANGAN PERNAH menggunakan badge / chip kecuali memang benar-benar penting/esensial untuk status data atau status sistem.**
> - **Hallucination Slop**: Inventing UI patterns that do not exist in PISICloud (e.g. Material chips/badges, generic SaaS sliders, nested floating glass cards) instead of following the actual clean bento/pill design system.
> - **Palette Slop**: Using generic AI SaaS colors (indigo/violet/purple gradients) instead of PISICloud's signature **Pine Green, Teal, Mint, and Charcoal palette**.
> - **Hardcoded Slop**: Writing raw English or Indonesian strings in templates instead of using **`ngx-translate`** (`{{ 'KEY' | translate }}`).
> - **Media Slop**: Using plain `<img>` tags without `NgOptimizedImage` (`ngSrc`), causing layout shifts (CLS), or forgetting `draggable="false"` and `select-none` on UI mockups.
> - **Legacy Angular Slop**: Writing `standalone: true`, `changeDetection: OnPush`, constructor DI, `*ngIf`/`*ngFor`, or `ngClass`/`ngStyle`.

Every AI Agent working on this codebase **MUST STRICTLY COMPLY** with the following engineering standards.

## 💎 1. ICONOGRAPHY SYSTEM: `@ng-icons` ONLY

This project uses **`@ng-icons/core`** with **`@ng-icons/bootstrap-icons`** and **`@ng-icons/tabler-icons`**.  
**RULE**: Never write large raw inline SVGs for standard icons. Always use `NgIcon` with `provideIcons`.

### How to use `@ng-icons` properly:

```typescript
import { Component } from '@angular/core';
import { NgIcon, provideIcons } from '@ng-icons/core';
import {
  bootstrapTelephoneFill,
  bootstrapPlayCircleFill,
  bootstrapWhatsapp,
  bootstrapEnvelope,
  bootstrapX,
} from '@ng-icons/bootstrap-icons';
import { tablerArrowUpRight } from '@ng-icons/tabler-icons';

@Component({
  selector: 'app-example-section',
  imports: [NgIcon],
  viewProviders: [
    provideIcons({
      bootstrapTelephoneFill,
      bootstrapPlayCircleFill,
      bootstrapWhatsapp,
      bootstrapEnvelope,
      bootstrapX,
      tablerArrowUpRight,
    }),
  ],
  templateUrl: './example-section.html',
})
export class ExampleSection {}
```

### Template Usage:

```html
<!-- Button Icon -->
<ng-icon name="bootstrapTelephoneFill" class="text-base mr-2 text-white" aria-hidden="true" />

<!-- Action Icon -->
<ng-icon name="bootstrapPlayCircleFill" class="text-xl text-[#066b5b]" aria-hidden="true" />

<!-- Close / Modal Icon -->
<ng-icon name="bootstrapX" class="text-2xl text-slate-700" aria-hidden="true" />
```

This project uses **Angular Material 3** (`@angular/material`) integrated with **Tailwind CSS (v4)**.

| :-------------------------------- | :----------------------------------------------------- | :-------------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

| **Secondary CTA Button (Pill)**   | `button[mat-stroked-button]` / `a[mat-stroked-button]` | `MatButtonModule` (`@angular/material/button`)            | `<button mat-stroked-button class="rounded-full! border-[#066b5b]! text-[#066b5b]! hover:bg-white/80! bg-white/40! px-6! py-3.5! h-auto! font-medium! text-sm! sm:text-base! shadow-xs! hover:shadow-md! active:scale-95! transition-all! duration-200!">...</button>` |
| **Icon Buttons / Action Toggles** | `button[mat-icon-button]`                              | `MatButtonModule` (`@angular/material/button`)            | `<button mat-icon-button aria-label="Close" class="text-slate-700!">...</button>`                                                                                                                                                                                      |
| **Dropdown Menus & Popovers**     | `mat-menu`, `[matMenuTriggerFor]`                      | `MatMenuModule` (`@angular/material/menu`)                | `<button mat-button [matMenuTriggerFor]="menu">...</button><mat-menu #menu="matMenu" class="rounded-2xl!">...</mat-menu>`                                                                                                                                              |

### Tailwind `!` (Important) Modifier for Material Override:

Always use Tailwind v4's `!` modifier (e.g., `rounded-full!`, `bg-[#066b5b]!`, `text-white!`, `px-7!`, `py-3.5!`, `h-auto!`) when styling Material buttons so the default fixed height (40px/48px) and default border radius are overridden cleanly while preserving MDC ripple animations and accessibility semantics.

### 🚫 BADGE & CHIP RESTRICTION (STRICT POLICY):

- **Jangan pernah menggunakan badge / chip / tag pill dekoratif** (seperti `mat-chip`, `<span class="inline-flex rounded-full bg-emerald-100 ...">✨ OVERVIEW</span>`, badge "NEW", "FEATURE", dll.) di atas heading atau di dalam card, **kecuali memang benar-benar penting dan esensial** untuk merepresentasikan status data atau status sistem yang dinamis.
- Desain PISICloud mengutamakan kesederhanaan, tipografi dua warna yang bersih, dan whitespace yang proporsional—bukan hiasan badge/chip kecil yang membuat UI berantakan (cluttered).

- **Country Flag Emojis**: Handled by `country-flag-emoji-polyfill` in `main.ts` with class `.font-flag` (`Twemoji Country Flags`).
- **Signature Two-Tone Heading Formula**:
  ```html

    class="text-3xl sm:text-4xl lg:text-5xl font-bold text-[#191c1b] tracking-tight leading-tight"

    <span>{{ 'PAGE.SECTION.TITLE_PREFIX' | translate }} </span>
  ```

- **Typography Scale**:
  - `H1 / Display`: `text-3xl sm:text-4xl md:text-5xl lg:text-[54px] font-bold tracking-tight leading-[1.15]`

  - `Body Text`: `text-sm sm:text-base lg:text-lg text-slate-600 leading-relaxed font-normal`

## 🌐 5. ZERO HARDCODED STRINGS (100% `ngx-translate`)

- **NEVER** write raw text in HTML templates. Every title, paragraph, button label, tooltip, and image `alt` MUST use `ngx-translate`.
- Syntax: `{{ 'PAGE.SECTION.KEY' | translate }}` or `[attr.aria-label]="'PAGE.SECTION.KEY' | translate"`.
- When adding new components, add the corresponding translation keys to **all** `public/i18n/*.json` files (`en.json`, `id.json`, `zh.json`, `ja.json`, `ko.json`).
- Key structure: `[PAGE].[SECTION].[ELEMENT]` (e.g., `LANDING.HERO.TITLE_LINE_1`).

## 🖼️ 6. IMAGES, VIDEO & MEDIA PERFORMANCE

- **Mandatory `NgOptimizedImage`**: Always use `ngSrc` with explicit `width` and `height` attributes to prevent Cumulative Layout Shift (CLS).
- **Format**: All product images in `public/images/` must be optimized `.webp` or `.svg`.
- **LCP Optimization**: Add `priority` to above-the-fold hero images.
- **UI Mockup Protection**: Always apply `draggable="false"`, `(dragstart)="$event.preventDefault()"`, and `select-none` on UI illustration mockups.
- **Video Media**: Use **`@videojs/html`** with `<video-player>` and `<video-skin>` for high-quality Mux MP4 video playback in modal overlays.

## 🏗️ 7. ARCHITECTURAL & LAYOUT RULES

### 1. Root Layout Isolation (`src/app/app.html`)

The application root template contains:

```html
<universal-navbar />
<router-outlet />
<demo-video-modal />
<universal-interested />
<universal-footer />
```

⚠️ **CRITICAL RULE**: Because `<universal-navbar>`, `<universal-interested>`, `<demo-video-modal>`, and `<universal-footer>` are already rendered in `app.html`, **NEVER** include or duplicate them inside individual page templates (`src/app/pages/*/*.html`).

### 2. Page & Section Separation

- **Pages (`src/app/pages/[page-name]/`)**:
  - Pages are thin orchestrators.
  - A page template contains **ONLY** section component invocations (e.g., `<landing-hero />`, `<landing-features />`).
  - A page `.ts` only imports those section components and resolves route parameters or high-level signals.
- **Section Components (`src/app/components/[page]/[section-name]/`)**:
  - Every visual section MUST be its own standalone Angular component located in `src/app/components/[page]/[section-name]/`.
  - Reusable, universal sections live in `src/app/components/universal/[component-name]/`.
- **Angular CLI**: Always use Angular CLI (`ng generate component ...`) to scaffold new components.

## ⚡ 8. ANGULAR (v22+) BEST PRACTICES

- **Standalone Components**: Do NOT set `standalone: true` in `@Component` decorators (it is default in v20+).
- **Change Detection**: Do NOT set `changeDetection: ChangeDetectionStrategy.OnPush` explicitly (it is default in v22+).
- **State Management**: Use Angular Signals exclusively (`signal()`, `computed()`, `input()`, `output()`). Do NOT use `mutate`; use `update` or `set`.
- **Host Bindings**: Do NOT use `@HostBinding` or `@HostListener`. Use the `host: { ... }` object in `@Component`.
- **Class & Style Bindings**:
  - Do NOT use `ngClass`; use `[class.my-class]="condition"` or `[class]="expression"`.
  - Do NOT use `ngStyle`; use `[style.property]="expression"`.
- **Control Flow**: Use native Angular control flow (`@if`, `@for (track ...)`, `@switch`, `@let`, `@defer`) instead of structural directives (`*ngIf`, `*ngFor`).
- **Dependency Injection**: Use `inject(Service)` instead of constructor injection.
- **Routing**: Use `loadComponent: () => import(...).then(m => m.Component)` for lazy loading in `app.routes.ts`.

## ♿ 9. ACCESSIBILITY (A11Y) & SEO

- Every interactive element (button, link, modal toggle) MUST have an accessible name (`aria-label`, `aria-labelledby`, or text content).
- Collapsible accordions, menus, and drawers MUST update `aria-expanded`, `aria-controls`, and `aria-hidden` properly.
- Hidden dialogs/drawers must apply `inert` attribute when closed to prevent tab-trapping outside viewport.
- Focus rings: All interactive elements must have visible focus rings (`focus-visible:ring-2 focus-visible:ring-[#066b60] focus-visible:ring-offset-2 focus-visible:outline-none`).
- Color contrast: All text must strictly comply with WCAG AA (minimum 4.5:1 for normal text, 3:1 for large headings).
